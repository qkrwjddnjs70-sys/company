# 🏁 미니 카트 대소동

Claude Code로 만든 **1인칭 시점 미니 카트 레이싱 게임** 데모입니다.
빌드나 서버 없이 브라우저에서 `index.html` 파일 하나만 열면 바로 플레이할 수 있습니다.

## 목적

사내 "AI 활용 사례" 데모용으로, 대화 몇 번으로 기획 → 물리 엔진 → 1인칭 의사(疑似) 3D 렌더러 →
캐릭터/사운드/HUD/미니맵까지 갖춘 게임을 처음부터 끝까지 AI가 작성했다는 것을 보여줍니다.

## 실행 방법

`kart-game/index.html` 파일을 더블클릭해서 브라우저로 열면 됩니다. (별도 설치 불필요)

```bash
# 또는 간단히 로컬 서버로 열어도 됩니다
npx http-server kart-game
```

## 게임 방법

1. 캐릭터(여우/고양이/곰/토끼/판다/개구리)를 하나 고른다.
2. 방향키(↑↓←→) 또는 W/A/S/D로 핸들을 조작해 3바퀴를 돈다.
3. 노란 별 부스터 패드를 밟으면 일시적으로 가속된다.
4. 우하단 미니맵으로 트랙 위 내 위치와 상대 순위를 확인한다.
5. 모바일에서는 화면 하단 터치 버튼으로 조작 가능하다.

## 기술적으로 눈여겨볼 점

- **물리/AI는 위에서 내려다본 2D 트랙 좌표계(x, y, 각도)** 로 그대로 계산하고,
  **화면에 그릴 때만 1인칭 카메라로 원근 투영**해서 렌더링합니다. (물리와 렌더링을 분리)
- 트랙은 둥근 사각형을 아크(arc)+직선 세그먼트로 정의하고 420개 지점으로 샘플링해 재사용합니다.
- 오디오는 외부 파일 없이 `Web Audio API` 오실레이터로 즉석에서 효과음을 합성합니다.
- 캐릭터 그래픽은 이모지 + 캔버스 도형 조합이라 이미지 에셋이 전혀 없습니다.
